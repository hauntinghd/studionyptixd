# Skill 04 Companion — Description Bank

This is the runtime companion to Skill 04 (Description Writing). Skill 04 documents the structural slots and rules. This file provides:

1. **First-125 character bank** — 16 worked examples by niche, annotated for SEO load and emotional hook
2. **Chapter title bank** — 24 strong examples + 8 weak examples with diagnoses
3. **Lead magnet naming bank** — 12 worked names with annotations
4. **Five full worked descriptions** spanning niches (only 1 lived in Skill 04; this adds 4 more)
5. **Description anti-pattern bank** — 6 patterns that look correct but fail

The agent loads this when generating descriptions. Pulling from a bank of annotated examples is faster and more consistent than synthesizing from rules alone.

## 1. First-125 character bank

The first 125 characters carry the most SEO weight, get indexed for search, and appear in the search results below the title. They are the only part of the description some viewers ever see. They're also the slot where most descriptions waste opportunity with generic openers.

Each example below is annotated for: keyword load, emotional hook, and what slot is being prioritized.

> *Friday May 1 is days away. SSI lands May 1, but the next regular Social Security retirement payment doesn't hit until May 13.*
> Keywords: "Friday May 1," "SSI," "Social Security retirement payment." Hook: imminence + a specific 13-day gap. Why it works: time anchor self-selects retirees who track payment dates.

> Keywords: "Social Security," "debt flagged," "form." Hook: pre-2010 specificity + actionable solution. Why it works: niche-specific cohort + immediate-action promise.

## 3. Lead magnet naming bank

The lead magnet name is the single most-clicked text in the description. A generic name ("Free Guide") loses to a specific name ("2026 Retiree Protection Checklist") by 3-5× signup rate.

### Strong lead magnet names

> *2026 Retiree Protection Checklist*
> Why it works: year + cohort + specific document type. Personal-finance authority channel canonical.

> *The Senior Health Vitamin Stack (Ages 65+)*
> Why it works: specific outcome + age-gating. Medical-authority channel canonical.

> *The 9-Page IRS Audit Defense Kit*
> Why it works: page count + specific use-case. Concrete enough to feel real.

> *The Cursor Power-User Setup Guide (47 Pages)*
> Why it works: tool name + power-user framing + page count.

> *The 30-Day AI Stack Newsletter*
> Why it works: time anchor + frequency commitment.

> *The First-Time Homebuyer Closing-Costs Calculator*
> Why it works: specific cohort + specific document type + tool framing.

> *The Type 2 Diabetes Reversal Food List (Cited Clinical Source)*
> Why it works: condition + outcome + cited authority.

> *The Investigative Journalism Source Toolkit*
> Why it works: specific genre + tool framing. Investigative-journalism style.

### Weak lead magnet names + diagnosis

> *Free Guide*
> Diagnosis: zero specificity. The reader cannot predict value. Signup rate near zero.

> *My Newsletter*
> Diagnosis: deliverable type without value. Replace with "The 30-Day AI Stack Newsletter."

> *Free PDF Download*
> Diagnosis: format-only. Add a specific outcome.

> *Click here for more info*
> Diagnosis: reads spammy. Replace with the actual deliverable name.

## 5. Description anti-pattern bank

Six descriptions that look correct but fail. Diagnoses attached.

### Anti-pattern 1 — *Generic In-This-Video Opener*

```
Welcome back to the channel guys! In this video we're going to be talking about Social Security and some changes coming up that you might want to know about...
```
Diagnosis: wastes the SEO-load-bearing first 125 chars on welcome filler. Generic "you might want to know" is the lowest CTR possible. Fix: replace with the niche-keyword-dense hook from §1.

### Anti-pattern 2 — *Lead Magnet Below the Affiliate*

```
[chapters]
💰 Tax-software affiliate
[long pitch]
👉 [tax software link]
📋 Free guide
👉 [lead magnet link]
```
Diagnosis: order is reversed. Lead magnet builds the trust that lets the affiliate convert. Putting the affiliate first signals monetization-priority and reduces lead magnet signup by ~40%. Fix: lead magnet ALWAYS comes immediately after chapters; affiliate after lead magnet.

### Anti-pattern 3 — *Multiple Affiliate Links*

```
💰 Cursor (affiliate link 1)
💰 Cursor Pro (affiliate link 2)
💰 Cursor Annual (affiliate link 3)
💰 Vercel (affiliate link 4)
```
Diagnosis: dilutes click. Reader picks zero. The data is consistent: one affiliate per video gets ~3× the clicks of multi-affiliate descriptions. Fix: one product per video.

### Anti-pattern 4 — *Generic Chapter Titles*

```
00:00 — Introduction
05:00 — Background
10:00 — More information
15:00 — Some examples
20:00 — Conclusion
```
Diagnosis: zero curiosity, zero retention lift, zero "key moments" search opportunity. The chapters function as labels, not hooks. Fix: every chapter is a curiosity-gap title from §2.

### Anti-pattern 5 — *Stale Affiliate*

```
💰 Tax-software affiliate (in a video posted in July, four months after tax season)
```
Diagnosis: dead air. Affiliate clicks vanish out of season. Fix: omit the affiliate slot entirely when seasonal. Resume when the season returns.

### Anti-pattern 6 — *Year-Stamped Title in Description*

```
2024 ULTIMATE GUIDE TO SOCIAL SECURITY — Everything You Need to Know!
```
Diagnosis: the description references the title's year, locking the video to a calendar year. On Jan 1 2025 the perceived freshness craters even though the content may still be valid. Fix: drop the year from the title and the first 125, OR commit to refreshing the title annually.

## 6. Runtime cite-from-bank workflow

When generating a description for any video:

1. **Identify niche** from channel + topic.
2. **Pull first-125 template** from §1 closest to the niche. Adapt to the specific topic with: keyword-dense, specific anchor (date/dollar/cohort), emotional hook, no fluff.
3. **Generate context paragraph** expanding the hook in 200-400 chars.
4. **Generate chapter timestamps** from script beats. Each chapter title cites a strong example pattern from §2.
5. **Insert lead magnet** using the channel's locked name (and consult §3 for naming patterns if creating a new magnet).
6. **Insert affiliate** if applicable and not seasonally dead.
7. **Insert disclaimer** for YMYL niches.
8. **Run anti-pattern audit** against §5.
9. **Audit total length** — 2,000-5,000 chars.
10. **Surface to user** with the citation showing which template the first 125 was based on.

The agent never invents a description from scratch. It adapts from the bank, audits against anti-patterns, and surfaces with citation visible.
