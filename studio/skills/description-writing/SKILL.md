# Skill 04 — Description Writing

This is the operational knowledge an AI YouTube agent needs to write a perfect description for any video in any niche. Lighter weight than Skills 01-03 because the description is a more constrained surface — it has fixed structural slots and most of its job is mechanical.

But mechanical doesn't mean unimportant. A well-written description controls SEO discoverability, conversion to lead magnets, affiliate revenue, viewer retention through chapters, and the channel's compliance footprint.

---

## 1. The job of a description

A description does six things in a single ~5,000-character text block:

1. **Wins SEO ranking** for the niche keywords — the first 125 characters are the most-weighted portion
2. **Drives clicks to the lead magnet** — the channel's email capture engine
3. **Drives affiliate revenue** through embedded links
4. **Improves retention** via chapter timestamps that let viewers navigate
5. **Pre-screens the right viewers** through tone and detail level
6. **Maintains compliance** — disclaimers, FTC affiliate disclosure, age-restriction signals

The agent never writes a generic "watch this video about X" description. Every description fills six structural slots, in this order:
1. Hook paragraph (125 chars to win SEO + reader engagement)
2. Context paragraph (200-400 chars expanding the value proposition)
3. Chapter timestamps (always)
4. Lead magnet CTA (channel-specific)
5. Affiliate / sponsorship pitch (when applicable)
6. Disclaimer + tags + hashtags

## 2. The first 125 characters

YouTube's algorithm and search index weight the first 125 characters more than any other part of the description. This is the section that:
- Shows up in search results below the video title
- Gets indexed for keyword ranking
- Is visible in the "below fold" preview before the user clicks "show more"

The agent writes the first 125 characters with these rules:
- **Lead with the most search-relevant keywords** (matching title keywords + niche terms)
- **Make it readable as a standalone sentence** — not keyword stuffing
- **Hook the reader emotionally** — the SEO read also has to make the human want to click "show more"
- **No URL, no CTA, no hashtag in this slot** — pure context

**Bad first 125:**
> Welcome back to the channel guys! In this video we're going to be talking about Social Security and some changes coming up that you might want to know about...

**Good first 125:**
> Friday May 1 is days away. SSI lands May 1, but the next regular Social Security retirement payment doesn't hit until May 13.

The good version: keyword-dense (Social Security, May 1, SSI, retirement payment), readable, hooks emotionally, leaves the reader wanting more.

## 3. The chapter timestamps

Every long-form video over 8 minutes gets chapter timestamps. Non-negotiable.

**Why:** Chapters multiply retention. Viewers who chapter-skip into a section they care about often watch through the rest of the video. Chapters also unlock the "key moments" feature in YouTube search results, which can drive 10-15% additional CTR for the video over time.

**Format rules:**
- Always start with `00:00` as the first timestamp (required for chapters to activate)
- Each subsequent timestamp must be ≥10 seconds after the previous (YouTube enforces this)
- Use `MM:SS` for videos under 60 minutes, `HH:MM:SS` for over
- Each chapter title is a punchy 4-8 words — describes what's in the chapter, no fluff
- 6-12 chapters total for a 25-minute video (one every 2-4 minutes)

**Bad chapter:**
```
00:00 - Introduction and welcome
01:30 - Some background information about the topic
```

**Good chapter:**
```
00:00 — The 13-day gap nobody warned you about
03:00 — The 5 rights buried in your Account Agreement
```

The good version: each chapter title is itself a curiosity gap. Viewers scrolling chapters click into the one that hits.

## 4. The lead magnet CTA

The most important single sentence in any description for channels using a lead magnet (email capture). For a personal-finance authority channel: the Retiree Protection Checklist. For a medical-authority channel: the senior health guide.

**Format rules:**
- Use a 📋 or 🎁 emoji to draw eye attention (this is one of the rare emoji exceptions — it's at the start of a paragraph, not in the title)
- Headline-case the offer name on its own line
- One paragraph (3-5 sentences) explaining what's in it and why it's valuable
- One bold URL (with arrow emoji 👉 — also a rare emoji exception)
- The URL goes on its own line, not embedded in prose

**Standard structure:**
```
📋 FREE [YEAR] [TOPIC] CHECKLIST
[2-3 sentence value prop describing exactly what's in the guide]
👉 https://[channel].kit.com/checklist
```

**Why this format:**
- Emoji at the start = visual break that catches scrolling eye
- Headline = makes the offer scannable
- Specific value prop = pre-sells the email signup
- 👉 emoji + URL on its own line = highest click rate

The agent never buries the lead magnet in mid-paragraph or after the affiliate. The lead magnet always comes immediately after the chapters.

## 5. The affiliate pitch

When the channel has affiliate partnerships, the affiliate goes after the lead magnet, not before. The lead magnet builds trust; the affiliate monetizes that trust.

**Format rules:**
- One product per video (don't dilute)
- 2-3 sentences of why this product fits this channel's audience
- One link, not multiple
- FTC-compliant disclosure: "This is an affiliate link. Using it supports the channel at no additional cost to you."

**Standard structure:**
```
💰 [PRODUCT NAME]
[2-3 sentences on what it is + why this audience needs it]
👉 [affiliate link]
(This is an affiliate link. Using it supports the channel at no additional cost to you.)
```

When the affiliate is dead/seasonal (e.g., a tax-software affiliate post-tax-season), the agent omits this slot rather than running a stale pitch.

## 6. The disclaimer

Required for finance, health, legal, civic (YMYL) niches. Skipped for entertainment, gaming, comedy, vlog.

**Standard format:**
```
⚠️ DISCLAIMER
This video is for educational purposes only and does not constitute [legal/medical/financial] advice. [Specific note if needed: "Patient stories are composites." / "Consult a [credential] before making any changes."]
```

The disclaimer goes after the affiliate, before the hashtags.

## 7. Tags and hashtags

YouTube's tag system was significantly de-prioritized in 2018 and is now a minor SEO signal at best. But it's still worth using:
- 15-25 tags per video
- Most-relevant first (first tag carries most weight)
- Mix of niche-broad ("social security") and niche-specific ("SSA form 634")
- Include the channel's brand name as a tag
- Tags don't need to be visible in the description

Hashtags are different and visible:
- 3 hashtags maximum (any more and YouTube ignores all of them)
- All 3 should be niche-relevant
- One broad ("#SocialSecurity"), one specific ("#SSAOverpayment"), one branded (the channel's own brand tag)
- Hashtags appear above the title on YouTube and link to feeds of all videos using that tag

The agent always uses exactly 3 hashtags in the description body (typically last line). Tags go in YouTube's tag field, not visible in description.

## 8. Niche-specific description playbooks

Same 22 niches as title/thumbnail. Each has a description template variant. Lighter coverage here since description is more mechanical than title or thumbnail.

### Senior finance / IRS / retirement (personal-finance authority register)
- **First 125:** specific deadline + threat
- **Lead magnet:** Retiree Protection Checklist, 42 pages, ssa form references
- **Affiliate:** Tax software (seasonal) or financial advisor matching
- **Disclaimer:** required, finance + legal
- **Hashtags:** #SocialSecurity / #SSA[Specific] / #[Channel]

### Tech / AI / dev tools
- **First 125:** product name + verdict tease
- **Lead magnet:** newsletter or playbook
- **Affiliate:** product purchase link, course
- **Disclaimer:** none usually
- **Hashtags:** #[Product] / #AI / #[Channel]

### Gaming / Roblox shorts
- **First 125:** punchy hook restate + game name
- **Lead magnet:** rare in this niche
- **Affiliate:** none usually
- **Disclaimer:** none
- **Hashtags:** #Roblox / #[GameName] / #[Channel]

### News-hijack documentary (investigative-journalism / geopolitics documentary register)
- **First 125:** named villain + specific number
- **Lead magnet:** newsletter / Patreon
- **Affiliate:** rare
- **Disclaimer:** sometimes (legal)
- **Hashtags:** #[Topic] / #Investigation / #[Channel]

### True crime
- **First 125:** victim name + date + place
- **Lead magnet:** sometimes (Patreon)
- **Affiliate:** none usually
- **Disclaimer:** "Out of respect for the families..."
- **Hashtags:** #TrueCrime / #[CaseName] / #[Channel]

### Health / medical / supplements (medical-authority / doctor-personality health register)
- **First 125:** body part + specific threat or solution
- **Lead magnet:** free health guide / symptom tracker
- **Affiliate:** supplement (ONE) or device
- **Disclaimer:** required, medical
- **Hashtags:** #[Condition] / #[Supplement] / #[Channel]

### Real estate / home
- **First 125:** dollar amount + city/property
- **Lead magnet:** newsletter
- **Affiliate:** mortgage calculator, course, broker referral
- **Disclaimer:** financial
- **Hashtags:** #RealEstate / #[Market] / #[Channel]

### Beauty / fashion / cooking / lifestyle
- **First 125:** product/dish/place name + specific claim
- **Lead magnet:** rare
- **Affiliate:** product links (multiple ok in lifestyle)
- **Disclaimer:** none
- **Hashtags:** niche-specific

### History / explainer / science / documentary long-form
- **First 125:** specific date/place/concept + tease
- **Lead magnet:** newsletter
- **Affiliate:** sponsor pitch (often Brilliant, Squarespace, etc.)
- **Disclaimer:** none
- **Hashtags:** #[Topic] / #History or #Science / #[Channel]

### Vlog / fitness / faith / politics / travel / reaction
- **First 125:** personal hook restate
- **Lead magnet:** rare except fitness (program PDF)
- **Affiliate:** product links sometimes
- **Disclaimer:** sometimes
- **Hashtags:** niche-specific

### Music videos / drill / propaganda
- **First 125:** track name + artist + brief mood-set
- **Lead magnet:** rare
- **Affiliate:** track on Spotify/Apple
- **Disclaimer:** none
- **Hashtags:** #[Genre] / #[Artist] / #[Channel]

### Ambient / sleep / focus
- **First 125:** "X hours of [type]" + use case ("for studying," "for sleep")
- **Lead magnet:** rare
- **Affiliate:** rare
- **Disclaimer:** none
- **Hashtags:** #LofiHipHop / #StudyMusic / #[Channel]

## 9. The competitor mining protocol

Lighter than for thumbnails or scripts because descriptions are more mechanical. The agent runs:

**Step 1 — Pull 5-10 descriptions** from outliers in the niche (3x channel median videos).

**Step 2 — Extract structural pattern.** Most channels have a locked description template. Tag the slots: hook → context → chapters → lead magnet → affiliate → disclaimer → tags.

**Step 3 — Extract first-125 patterns.** What hooks does the niche use? Specific numbers? Named villains? Time anchors?

**Step 4 — Extract chapter naming patterns.** Numbered? Question-led? Topic-led?

**Step 5 — Apply with brand differentiation.** Match the structural pattern but use the user's own brand voice and CTAs.

The agent doesn't deeply mine descriptions because they're heavily standardized within niches. The user's first 5 descriptions establish the channel's locked template; subsequent descriptions follow it.

## 10. The generation workflow

When the script + title + thumbnail are ready:

**Step 1 — Pull video metadata:** title, niche, channel CTAs (lead magnet URL, affiliate URL, disclaimer template), chapter timestamps from script beat structure.

**Step 2 — Write first 125.** This is the SEO-load-bearing portion. Lead with niche keywords + specific anchor.

**Step 3 — Write context paragraph.** Expand on the hook in 200-400 chars. Set up the chapters.

**Step 4 — Generate chapter timestamps from script beats.** Each beat in the 12-beat structure maps to a chapter timestamp. Convert to MM:SS or HH:MM:SS format.

**Step 5 — Write chapter titles.** Each one a 4-8 word curiosity gap, not a generic label.

**Step 6 — Insert lead magnet CTA** with the channel's standard format.

**Step 7 — Insert affiliate** (if applicable for this video and not seasonally dead).

**Step 8 — Insert disclaimer** for YMYL niches.

**Step 9 — Generate tags** (15-25, niche-relevant, brand name included).

**Step 10 — Pick 3 hashtags** (one broad / one specific / one branded).

**Step 11 — Self-validate length.** Total description should be 2,000-5,000 characters. Mobile users see only the first ~150 chars without expanding, but desktop users scan the whole block.

## 11. Anti-patterns

Description patterns that fail.

- **Generic "in this video" opener.** Wastes the first 125 SEO slot.
- **Burying the lead magnet at the bottom.** Lead magnet always after chapters, not after 5 paragraphs of fluff.
- **Multiple affiliate links in one description.** Dilutes click. One affiliate per video.
- **No chapter timestamps.** Loses the search "key moments" feature.
- **Generic chapter titles** like "Introduction" or "Conclusion." Curiosity-gap chapter titles instead.
- **Excessive emoji.** 2-3 strategic emoji (📋, 👉, ⚠️) is the cap. Emoji-stuffed descriptions read spammy.
- **No hashtags or more than 3.** YouTube ignores hashtags beyond 3.
- **Stale affiliate.** Running a tax software affiliate in July is dead air.
- **Year-stamping the description.** "2024 guide" dies on Jan 1 2025.
- **Wall of unbroken text.** Use line breaks generously.
- **External links to social platforms before the lead magnet.** Order is: lead magnet → affiliate → social.

## 13. Runtime checklist

Before any description surfaces:

- [ ] First 125 chars contain niche keywords + emotional hook
- [ ] Context paragraph expands without repeating
- [ ] Chapter timestamps generated from script beats
- [ ] Each chapter title is a curiosity gap, not a generic label
- [ ] Lead magnet appears immediately after chapters
- [ ] Affiliate (if applicable) appears after lead magnet
- [ ] Disclaimer present for YMYL niches
- [ ] 3 hashtags exactly (broad + specific + branded)
- [ ] No anti-patterns (generic opener, multiple affiliates, no chapters, etc.)
- [ ] Total length 2,000-5,000 chars
- [ ] All URLs validated and live

If any check fails, regenerate. Never surface a failing description.
