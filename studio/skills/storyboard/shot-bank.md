# Skill 06 Companion — Storyboard Shot Bank

This is the runtime companion to Skill 06 (Storyboard / Scene Breakdown). Skill 06 documents when to storyboard, the 4 commit gates, and the Storyboard Profile artifact. This file provides:

1. **Beat-to-shot mapping** — for each script structure (12-beat authority, vertical short, music video, news-hijack), a worked beat → shot count → timing table
2. **Long-form authority worked storyboard** — a 25-minute personal-finance authority example episode mapped to 52 shots (the missing example in Skill 06)
3. **Style lock bank** — 8 channel-archetype style locks (matched to the 8 archetypes in Skill 08's config bank)
4. **Shot list patterns** — the recurring shot patterns the agent pulls from (cold open, mechanism reveal, three-example cycle, numbered list segment, CTA close)
5. **Transition pattern bank** — per-niche transition discipline (cuts vs fades vs match vs whip)
6. **Anti-patterns** — 6 storyboard mistakes that cost re-renders

The agent loads this when storyboarding any video. Pairs with Skill 07's i2v cookbook (the cookbook gives shot-type prompts; this companion gives the shot list those prompts populate).

---

## 1. Why beat-to-shot mapping matters

Skill 03 says "write 25,000 chars across 12 beats." Skill 07 says "use Kling Pro for hook close-ups." But there's a missing layer: how many shots does each beat need, and at what duration?

A 12-beat 25-minute IRS script can be storyboarded as:
- 35 shots (under-shot, viewers feel staring at a single talking head)
- 50 shots (well-paced, top viral-challenge 8-second rule)
- 90 shots (over-shot, expensive and noisy)

The right answer is "50, with specific shot types at specific beats." This companion makes that answer cite-able.

---

## 2. Beat-to-shot mapping bank

### 12-beat long-form authority (25 min, 25,000 chars)

Target shot count: **48-55 shots** total. Average shot duration: ~28-32 seconds. The top viral-challenge creator's 8-second rule applies inside each shot via micro-cuts (B-roll inserts, text overlays, host-back-to-camera) — but those don't count as "shots" for storyboard purposes.

| Beat | Beat duration | Shot count | Shot types |
|---|---|---|---|
| 1. Hook | 30s | 4-5 | establishing exterior + hook close-up + 2-3 B-roll |
| 2. 5-Promise Stack | 60s | 3 | host on camera + 2 supporting visuals |
| 3. Credential Intro | 20s | 1 | authority intro |
| 4. Core Story | 3:30 | 8-10 | composite case shots + B-roll + transitions |
| 5. Mechanism | 3:30 | 6-8 | mechanism diagram + host explainer + B-roll |
| 6. Three Examples | 4:30 | 9-12 | 3-4 shots per example × 3 examples |
| 7. Numbered List | 5:00 | 8-10 | 1-2 shots per item, 5-7 items |
| 8. Bonus | 1:30 | 2-3 | mechanism diagram + B-roll |
| 9. Lead Magnet CTA | 1:00 | 2 | host on camera + lead magnet visual |
| 10. Affiliate | 30s | 1 | product visual |
| 11. Close | 1:30 | 2 | host on camera + B-roll callback |
| 12. Share Prompt | 30s | 1 | host on camera |

Total: 47-58 shots. Sweet spot 50-52.

### Vertical short (60-90s, ~3,000 chars)

Target shot count: **8-15 shots**. Average shot duration: ~5-8 seconds.

| Beat | Beat duration | Shot count |
|---|---|---|
| Hook (BRO!) | 15-20s | 2-3 |
| Premise expansion | 15-20s | 2-3 |
| Cascading consequences | 20-30s | 4-6 |
| Payoff + CTA | 10-15s | 2-3 |

### Music video (3:00-3:30, BPM-locked)

Target shot count: **40-70 shots**. Shot duration locked to bar length (3.5-4 sec at 130-145 BPM).

| Section | Duration | Shot count |
|---|---|---|
| Hook intro | 8 bars (~22s) | 6-8 |
| Verse 1 | 16 bars (~44s) | 12-16 |
| Chorus 1 | 8 bars (~22s) | 4-6 (recurring) |
| Verse 2 | 16 bars (~44s) | 12-16 |
| Chorus 2 | 8 bars (~22s) | 4-6 (recurring) |
| Bridge | 8 bars (~22s) | 4-8 (visual reset) |
| Chorus 3 | 8 bars (~22s) | 4-6 (recurring) |
| Outro | 4 bars (~11s) | 1-2 |

### News-hijack documentary (15-25 min)

Target shot count: **30-45 shots** + 60-100 B-roll inserts (lighter weight, often stock or document overlays).

| Section | Duration | Shot count | B-roll inserts |
|---|---|---|---|
| Hook with named villain | 60-90s | 3-4 | 5-8 |
| Investigation setup | 2 min | 4-6 | 8-12 |
| Evidence unfolds | 8-12 min | 12-18 | 30-50 |
| Reveal + implication | 2-3 min | 6-10 | 8-15 |
| CTA + close | 1 min | 2-3 | 3-5 |

### Documentary explainer (long-form mystery-documentary style, 12-18 min)

Target shot count: **40-60 shots**. Heavily image-driven; less host on camera.

| Section | Duration | Shot count |
|---|---|---|
| Cold open | 30-60s | 4-6 (mystery object + establishing) |
| Setup | 2-3 min | 8-12 (historical context visualization) |
| Complication | 3-5 min | 10-15 (conflict visualization) |
| Resolution | 3-5 min | 10-15 (reveal + evidence visualization) |
| Reflection | 1-2 min | 4-6 (callback to opening object) |

## 4. Style lock bank

The 8 channel-specific style locks. Each is the Visual Style DNA section of the Channel Profile, condensed for runtime citation.

### Personal-finance authority channel (V2 IRS authority)

```
COLOR GRADE: warm domestic interiors (golden hour kitchen) + cool institutional exteriors (navy blue Treasury). Slight desaturation overall (~85%).
LIGHTING REGISTER: window-key dominant for domestic shots; three-point professional for host shots; flat overcast for institutional exteriors.
COMPOSITION: rule of thirds dominant; centered for host shots only.
ASPECT RATIO: 16:9.
ACCENT PALETTE: warm tan + navy + selective red (for stamps/threats only).
SHOT-TYPE DEFAULTS: hook close-up = Kling 2.1 Pro; B-roll = Hailuo 02; mechanism = Veo 3 Fast; host = HeyGen avatar.
```

### Medical-authority channel (V2 medical authority)

```
COLOR GRADE: clean clinical bright (kitchen + clinic interiors) + slight warm grade on patient stories. Saturation ~95%.
LIGHTING REGISTER: bright clean overhead for clinic; warm window-key for patient kitchens.
COMPOSITION: rule of thirds; close-up macro on food/supplements.
ASPECT RATIO: 16:9.
ACCENT PALETTE: clinical white + soft teal + warm coral.
SHOT-TYPE DEFAULTS: same as the personal-finance authority profile but with more food close-ups (Veo 3 for water/oil physics).
```

### Roblox-scenario (V6 vertical hype)

```
COLOR GRADE: vibrant saturated, slightly stylized (blocky Roblox influence even in non-Roblox shots).
LIGHTING REGISTER: bright even, slight rim light.
COMPOSITION: centered for face shots; rule of thirds for environment.
ASPECT RATIO: 9:16.
ACCENT PALETTE: bright primary colors (red, blue, yellow).
SHOT-TYPE DEFAULTS: hook = Kling 2.1 Pro for face; environment = Hailuo 02; Roblox-style = LTX-2.3 if doing actual Roblox aesthetics.
```

### Brick-narrative storytelling channel (V14 drill music video)

```
COLOR GRADE: cinematic warm-cool gradient. Saturated. Sometimes slight film grain.
LIGHTING REGISTER: dramatic key + rim. Often sunset orange + cool ambient.
COMPOSITION: locked low-angle for hero shots; centered for chorus visuals.
ASPECT RATIO: 16:9 typically; 9:16 for shorts variant.
ACCENT PALETTE: full saturation, channel-specific (brick-toy yellow + green + red).
SHOT-TYPE DEFAULTS: all LTX-2.3 (volume + stylized aesthetic).
```

### Documentary explainer (V1 long-form mystery-documentary style)

```
COLOR GRADE: dark moody. Cool shadows. Warm key. Slight cinematic film grain.
LIGHTING REGISTER: single dramatic key + soft fill. Often single light source visible in frame (lamp, window, candle).
COMPOSITION: rule of thirds for objects; low-angle for atmosphere.
ASPECT RATIO: 16:9.
ACCENT PALETTE: muted with single object accent.
SHOT-TYPE DEFAULTS: mystery object = Kling 2.0 Standard; archival = Hailuo 02 (slight grain matches); reconstruction = Veo 3.
```

### Tech / AI dev (V8 Erudite Professor)

```
COLOR GRADE: clean modern. Slight cool grade. High saturation on key elements (terminal text, UI).
LIGHTING REGISTER: bright studio + screen glow.
COMPOSITION: rule of thirds; screen-as-subject acceptable.
ASPECT RATIO: 16:9.
ACCENT PALETTE: modern dev (#10A37F green, #6366F1 indigo, #F87171 red).
SHOT-TYPE DEFAULTS: host on camera = HeyGen or real footage; UI = direct screen capture; mechanism = Kling 2.0 Standard.
```

### News-hijack documentary (V4 investigative-journalism adjacent)

```
COLOR GRADE: cool blue forensic + warm document accents. Slight cinematic grain.
LIGHTING REGISTER: low-key for host; document-overlay-bright for evidence.
COMPOSITION: split screen common; document overlay on right third.
ASPECT RATIO: 16:9.
ACCENT PALETTE: forensic blue + red (for highlighted evidence) + warm document tone.
SHOT-TYPE DEFAULTS: host = real footage or HeyGen; documents = static composite (Hailuo 02); cinematic interludes = Kling 2.1 Pro.
```

### True crime (V13 Reluctant Witness)

```
COLOR GRADE: cool desaturated. Heavy. Slight blue cast on archival shots.
LIGHTING REGISTER: low-key. Single warm key light. Heavy shadow.
COMPOSITION: rule of thirds; centered for weighted moments.
ASPECT RATIO: 16:9.
ACCENT PALETTE: cool blue + cream + selective single warm accent (a victim's photo, a piece of evidence).
SHOT-TYPE DEFAULTS: mystery object = Kling 2.0 Standard; case file = Hailuo 02; reconstruction = Kling 2.1 Pro.
```

## 5. Shot list patterns

Five recurring shot patterns the agent pulls from. Each is a 3-5 shot mini-sequence the script needs at specific beats.

### Pattern A — The cold open (Beat 1, first 30s)

```
1. Establishing exterior (5s) — location and tone
2. Hook close-up (5-8s) — the moment of recognition
3. B-roll detail (3-5s) — the specific anchor (form, letter, document)
4. Authority intro (5-7s) — host on camera, brief
5. B-roll cycle (5s) — visual support for promise stack
```

This pattern recurs at the top of every 12-beat authority video. Locked.

### Pattern B — The mechanism reveal (Beat 5)

```
1. Mechanism diagram intro (5s) — the physical metaphor (cabinet, dominos, etc.)
2. Host explainer (15-20s) — host walking through it
3. Diagram showing key transition (5-10s) — the rule change visualized
4. B-roll evidence (5s) — the document or letter where it lives
5. Host re-anchor (10-15s) — back to the patient story
```

### Pattern C — The three-example cycle (Beat 6, repeats x3)

```
For each example (90s):
1. Establishing exterior matched to the example's location (5s)
2. Composite case shot — the patient in their kitchen (15-25s)
3. B-roll detail relevant to their specific situation (5-10s)
4. Number reveal — what they lost / when they lost it (5-10s)
```

3 cycles × 4 shots each = 12 shots for Beat 6.

### Pattern D — The numbered list segment (Beat 7, repeats x5-7)

```
For each item (60-90s):
1. Item visual / metaphor (5-10s) — form, button, calendar
2. Host explainer (30-45s) — host walking through the action
3. (Optional) B-roll showing the action being completed (10s)
```

5-7 items × 2-3 shots each = 8-10 shots for Beat 7.

### Pattern E — The CTA + close (Beats 9-12)

```
1. Lead magnet host shot (10-15s) — host presenting the checklist
2. Lead magnet visual (10s) — laptop showing the landing page
3. Affiliate visual + host (15-20s)
4. Host close — restating stakes (30-45s)
5. B-roll callback to Beat 4 patient (10-15s) — now empowered/protected
6. Host preview of next video (15-20s)
7. Share prompt + signature close (10-15s)
```

## 6. Transition pattern bank

Per-niche transition discipline. The agent picks the dominant transition vocabulary up-front and stays within it.

### Long-form authority (personal-finance authority, medical-authority)

- **Cuts:** dominant. ~85% of transitions are hard cuts. Authority register doesn't need showy transitions.
- **Cross-fades:** ~10% — used between scenes (different locations).
- **Match cuts:** ~3% — used at major reveals (cabinet drawer closing matches to filing window closing).
- **Whip pans:** never. Reads as YouTube hype, breaks authority register.
- **Wipes:** never. Reads as 2010s vlog.

### Music video (brick-narrative storytelling)

- **Beat-locked cuts:** dominant. ~70% of transitions land on the downbeat.
- **Whip pans:** ~15% — used at chorus returns.
- **Match cuts:** ~10% — used between hook and verse.
- **Cross-fades:** rare, used only on outro.

### News-hijack documentary

- **Cuts:** ~70%.
- **Cross-fades:** ~15% — used between investigation phases.
- **Document overlay slide-in:** ~10% — when evidence is presented.
- **Whip pans:** ~5% — used at major reveals.

### Vertical short (Roblox-scenario)

- **Hard cuts:** ~80% — short attention budget.
- **Whip pans:** ~15% — energy.
- **Match cuts:** ~5% — punchline payoffs.

### True crime

- **Slow cross-fades:** dominant. ~50% — pace is weighted.
- **Cuts:** ~40%.
- **Long fades to black:** ~10% — used at chapter breaks.
- **Whip pans:** never. Breaks reverent register.

### Documentary (long-form mystery-documentary style)

- **Slow cross-fades:** ~40%.
- **Cuts:** ~40%.
- **Match cuts:** ~15% — the genre's signature transition.
- **Long fades:** ~5% — used between major sections.

## 7. Anti-patterns

Six storyboard mistakes that cost re-renders or break flow.

### Anti-pattern 1 — Under-shotting a long-form video

A 25-minute authority script storyboarded as 30 shots. Average shot duration: 50 seconds. Viewer drops at 30% retention valley because the visual variety isn't there.
**Fix:** target 48-55 shots (30-second average). Add B-roll inserts and host-cuts to break long shots.

### Anti-pattern 2 — Over-shotting a vertical short

A 75-second Roblox short storyboarded as 25 shots. Average shot: 3 seconds. Viewer experience: noisy, can't track narrative.
**Fix:** target 8-15 shots. Each shot should hold long enough for the dialogue beat to land.

### Anti-pattern 3 — Wrong shot type for beat

Beat 4 (Patient Core Story) storyboarded as 8 host-on-camera shots. The story is the patient's; showing only the host narrating it kills the emotional pull.
**Fix:** Beat 4 needs 60-70% composite case shots (the patient on screen) + 20-30% B-roll + 10% host. Cite Pattern C from §5.

### Anti-pattern 4 — Style lock drift mid-video

First 10 minutes use cool institutional grade; minute 11 onward suddenly switches to warm domestic. Viewer perceives unprofessional.
**Fix:** style lock established in §4 must be honored across ALL shots. The grade only shifts when scene location shifts (interior to exterior), and the shift is graded as transition, not jump.

### Anti-pattern 5 — Mismatched transition vocabulary

Authority video using whip pans between every beat. Reads as YouTube hype; breaks credentialed expert register.
**Fix:** match transitions to niche from §6. Authority = cuts + cross-fades only.

### Anti-pattern 6 — No host-on-camera shots in long-form authority

A 25-minute IRS video storyboarded entirely as B-roll + composite case shots. The viewer never sees the host's face, breaking the credentialed expert relationship.
**Fix:** host-on-camera should be 25-35% of total shot count for long-form authority. Cite Pattern E from §5.

## 8. Runtime workflow

When storyboarding any video:

1. **Identify niche** from Channel Profile.
2. **Pull beat-to-shot table** from §2 for the script structure.
3. **Pull style lock** from §4 for the channel.
4. **Walk script beats** mapping each beat to its shot count via §2.
5. **For each beat, cite shot list pattern** from §5 (cold open, mechanism reveal, three-example cycle, numbered list, CTA close).
6. **Pick model per shot** by citing Skill 07 §3 selection matrix.
7. **Pick transitions** from §6 for the niche.
8. **Run anti-pattern audit** against §7.
9. **Run 4 commit gates** from Skill 06 §4 (Style Lock → Storyboard Text → Sample Keyframe → Sample i2v).
10. **Lock storyboard** in Storyboard Profile artifact (Skill 06 §5).

The agent does not invent storyboard structure. It cites the beat-to-shot table, applies channel style lock, walks shot list patterns, audits, runs commit gates. Storyboards become consistent across episodes — same shot patterns, same style lock, same transition discipline. Brand-load-bearing.
